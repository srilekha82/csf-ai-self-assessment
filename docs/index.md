# csf-ai-self-assessment

A self-assessment for cybersecurity and AI: one questionnaire with a NIST CSF 2.0 sheet and a NIST AI RMF 1.0 sheet,
tailored to the organisation. Start with the [README](https://github.com/srilekha82/csf-ai-self-assessment#readme) for
setup and the quick start.

| Page | Read it to… |
|---|---|
| [Guide](guide.md) | run the tool: every command, script and data file, and a glossary |
| [Architecture](architecture.md) | see how the stages fit together: bank building, questionnaire, answers, reports |
| [AI RMF model](ai-rmf-model.md) | understand or change the AI RMF track: AI areas, mapping, severity, question banks |

Rules for changing the code are in
[DESIGN_RULES.md](https://github.com/srilekha82/csf-ai-self-assessment/blob/main/DESIGN_RULES.md).
